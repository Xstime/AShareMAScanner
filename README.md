## v1.3.1 新功能

### 低位首板放量（3～5日）——第八种选股策略

以**当前扫描日**为基准，筛选 **3、4 或 5 个市场交易日前**出现一次疑似涨停的股票，符合全部条件：

- 按后复权收盘价涨幅近似判定涨停：常规沪深主板约 **9.7%～10.6%**，创业板和科创板约 **19.5%～20.6%**；ST/*ST 不参与。
- 首板前 **20 个有效交易日**不得出现同类涨停。
- 首板前一日的价格位于此前 **30 个有效交易日收盘区间的下部 35%**。
- 首板当日成交量 ≥ 此前 **5 个有效交易日平均成交量的 1.5 倍**。
- 显示首板日期、距今市场交易日、首板涨幅、放量倍数、首板前低位位置和当前股价相对首板的变化。

**重要限制**：这是仅凭后复权日线计算的**疑似涨停、疑似首板**，不是交易所认证的涨停记录，也无法判断是否炸板、封单状态、上市首日无价格限制或其他特别交易规则。涉及除权与低价股时可能误判。应将结果作为核查名单而不是已验证涨停名单。该策略仅用于个股；行业板块没有“首板”含义，显示“仅个股适用”。

### GitHub 下载进度窗口

仍须点击主窗口“检查更新”，不会在启动时静默检查。当发现更高版本，或同版本的发行文件 SHA-256 不同而需要重新下载时：

- 显示单独的 PySide6 下载子窗口：文件容量、百分比、平均速度和状态；
- 不设置**累计下载总时长**上限；网络每次读取使用 **30 秒无响应超时**，随后重连；
- 服务端支持 HTTP Range 时尝试断点续传，否则重新下载；支持用户取消并清理临时文件；
- 仍校验 GitHub Release 附件的 SHA-256、大小、Python 语法和版本，再安全更新并在启动失败时回滚。

v1.3.2 新增固定 HTTPS 镜像作为首选更新源；不提供可配置代理或第三方镜像。

## 原有八种策略

1. 放量突破 MA5
2. 放量突破 MA10
3. 放量突破 MA20
4. MA5 上穿 MA10
5. MA5 首次拐头向上
6. MA5/MA10/MA20 粘合后首次向上发散
7. 放量倍数 + 换手率自定义区间
8. 低位首板放量（3～5 交易日）

## 安装和数据

[GitHub Releases](https://github.com/Xstime/AShareMAScanner/releases) 下载 `AShareMAScanner_v1.3.3.pyw` 或 `AShareMAScanner_v1.3.3.zip`。直接运行 `python A股MA扫描器_v1.3.3.pyw`（系统需有 Python 3.10+ 和 Tkinter；依赖库可按提示安装）。`python A股MA扫描器_v1.3.2.pyw --demo` 可不联网查看主界面。

数据库始终放在程序文件同级的 **`data/a_share_baostock_hfq.db`**，采用 SQLite/WAL；升级时**不要删除或移动 `data/`**。新版不修改 `daily` 表结构、不清空缓存、不重新下载全部历史数据。仍保留 45 交易日左右的 BaoStock 行情缓存、断点补抓、三阶段 GUI、8 阶段更新进度和同花顺行业 TOP5。

旧版 `A股MA扫描器_v1.3.0.pyw`、`A股MA扫描器_v1.3.1.pyw`、`A股MA扫描器_v1.3.2.pyw` 保留在仓库以供回归验证。发行使用独立的 `A股MA扫描器_v1.3.3.pyw` 源文件，避免覆盖旧版本源文件。
